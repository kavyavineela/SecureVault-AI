# 🔐 SecureVault AI

SecureVault AI is a production-style cybersecurity mobile application built using Flutter, FastAPI, MongoDB, and AI.

## 🚀 Features

- Secure Authentication
- Password Manager
- Secure Notes
- Secure Documents
- AES Encryption
- SHA-256 Hashing
- Biometric Login
- AI Password Strength Analysis
- AI Phishing Detection
- Threat Dashboard

## 🛠️ Tech Stack

- Flutter
- Dart
- FastAPI
- MongoDB
- Python
- Docker
- GitHub Actions
